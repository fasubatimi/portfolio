I’m Kunle, a software developer based in Lagos, Nigeria. I build apps and systems around problems that people actually face in their day-to-day lives.

Living and developing software in Lagos gives you a distinct perspective on technology. When network bandwidth fluctuates, servers encounter latency, and users face urgent constraints, software cannot afford to be fragile or bloated. It has to work reliably on modest hardware, fail gracefully when offline, and provide immediate clarity without cognitive friction.

My focus is centered on Native Android development using Java 17, cloud integrations with Firebase (Realtime Database, Authentication, and Storage), open-source mapping with OSMDroid, and distributed systems architecture. Whether it is an emergency reporting system like SafeAlert, a local network terminal management tool like Library Control, or an inventory system like Dansamdolly, I care deeply about how software is built from the inside out.

Core Engineering Principles

01. Clarity over cleverness

I favor explicit architectures, readable code, and predictable system states over obscure one-liners or fragile abstractions. If a fellow developer or teammate cannot understand the codebase within minutes, the architecture has failed.

02. Dependability under stress

Software must behave predictably under sub-optimal conditions. That means implementing robust local caching, graceful network degradation, zero-bloat dependencies, and defensive error handling.

03. Ownership end to end

I take responsibility for a feature from requirements through implementation, testing, and iteration. I would rather ship something focused that works reliably than something broad that breaks under real use.

Opportunities I Am Seeking

I am actively seeking software engineering roles. I thrive in teams that value engineering discipline, peer code review, and building tools people rely on. If you have an opportunity or would like to review my code, please reach out.
